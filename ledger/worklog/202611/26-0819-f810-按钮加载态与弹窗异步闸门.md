## Background

用户 2026-11-26 提出一组相对较大的能力，要求单独建任务认领、写清背景后实施。原话要点：

1. **Button loading**：参考 `/code/dsh-plugins/dsh-plugin-core` 的 loading。按钮左右宽度不能变。有 icon 时用 loading 图标替换原 icon，尺寸保持不变；没有 icon 时把文字隐藏、整个按钮变成一枚转圈。用户明确**接受不做自动测宽设宽**：「不用自动设宽，就跟我给你的参考项目一样：有 icon 就替换 icon，没有 icon 就直接整个变成转的按钮」。用户判断这应在 Button 层实现，不是 Dialog 层。
2. **Dialog 异步闸门**：弹窗一旦带按钮就应具备屏蔽能力——异步期间屏蔽弹窗内所有可点区域，含输入控件、关闭按钮、点遮罩关闭、其他按钮；同时支持白名单：把其他都屏蔽，只保留某一个按钮可点。用户指出本库「目前完全没有实现」。
3. **视觉不要回问用户**：「锁的视觉这个东西，你不要问我，去参考那个成熟项目是怎么做的」。已按此定稿，参考成熟项目自行决策，不再把视觉方案抛回用户。

用户要求与架构师 / 前端 / UX 一起讨论、参考成熟项目后给具体可实施合理方案；对自动设宽的让步见上。

## To Do

框架目标：把「闸门的唯一判定」立成一处契约，所有控件与所有关闭路径都调用它。不接受逐分支 / 逐控件 / 逐演示打补丁。

1. **闸门单一真源**（`src/ui/infra/popup-lock.ts`）：定义 `GateDecision`（locked / exempt / reason）与唯一判定 `decideGate(state, key)`；现有 `isPopupLockExempt` / `usePopupLocked` 收敛为它的薄封装，杜绝第二套判定。锁状态形状（blocked + exceptions + 嵌套合并）保持，作为 `Popup` 与命令式 Dialog 共用的唯一入口。
2. **控件统一接入协议**：把「读闸门 → 判定 → 短路交互 / 还原视觉」收成一个 hook `useControlGate(key?)`（返回 `locked` / `exempt` / `gateProps`）。Button / Switch / Segmented / Cell / Card / NavBar / Popup 关闭叉 / Overlay 全量接入；键盘焦点守卫（blur/Tab）在 hook 里统一做，WebView 的 CSS 命中层继续保留作第二道。禁止在每个控件里散写 `usePopupLock + isPopupLockExempt`。
3. **Dialog 关闭路径单一入口**：`DialogHost` 五条关闭入口（confirm / cancel / 自定义 action / 关闭叉 / 遮罩）统一经一个 `requestClose` 门——它本身就是闸门的命令式投影；`cancel` 不再位于 busy gate 之前，`locked={false}` 硬编码删除，锁状态只来自 `busy` 派生的 `blocked`。`onConfirm` / `onAction` 返回 Promise 期间整框屏蔽，false / reject 保持打开可重试。
4. **Button loading 正交化**：`loadingMode` 的 `auto` 档不再看定宽，视觉语义恒由「有无 icon / glyph」决定——有则 Spinner 顶替图标位，无则文字 `visibility:hidden` 占位 + 绝对定位 Spinner，按钮宽高一点不变；`inline` 只作为显式逃生口保留。不做 idleWidth 测宽设宽。
5. **失败反馈进契约**：`DialogOptions.onFailed`（reject / 显式 false 时回调，Promise 形式）随闸门一并给出，不专门为 demo 加 API。
6. **对外出口与契约闭环**：`popup-lock` / `useControlGate` / `decideGate` 从 `src/ui/infra/index.ts` 与 package exports 细粒度导出，登记 `docs/api/exports.md`、补 `scripts/check.mjs` requiredExports 与 `tests/tree-shaking.test.mjs` 断言。
7. **行为级验证**：以 dist 真渲染断言宽度不变 / 三态 loading / 整框锁 / 白名单例外 / 五条关闭路径 / 失败保持打开；真机补 WebView + Skyline 双端验证点（未真机前不宣称可用）。
