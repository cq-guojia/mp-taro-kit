## Background

用户 2026-11-26 提出一组相对较大的能力，要求单独建任务认领、写清背景后实施。原话要点：

1. **Button loading**：参考 `/code/dsh-plugins/dsh-plugin-core` 的 loading。按钮左右宽度不能变。有 icon 时用 loading 图标替换原 icon，尺寸保持不变；没有 icon 时把文字隐藏、整个按钮变成一枚转圈。用户明确**接受不做自动测宽设宽**：「不用自动设宽，就跟我给你的参考项目一样：有 icon 就替换 icon，没有 icon 就直接整个变成转的按钮」。用户判断这应在 Button 层实现，不是 Dialog 层。
2. **Dialog 异步闸门**：弹窗一旦带按钮就应具备屏蔽能力——异步期间屏蔽弹窗内所有可点区域，含输入控件、关闭按钮、点遮罩关闭、其他按钮；同时支持白名单：把其他都屏蔽，只保留某一个按钮可点。用户指出本库「目前完全没有实现」。

2. ✅ **控件统一接入协议**：Button / Switch / Segmented / Cell 都从 `useControlGate(lockKey)` 接入，把 `gate.locked` 并入自身 `disabled`、例外时给 `__lock-exempt` 类；各自加了 `lockKey` prop。Popup 关闭叉（`lockKey="close"`）与遮罩（`isPopupLockExempt('overlay')`）走同一判定。键盘 blur/Tab 守卫未做——小程序无 DOM 焦点语义，WebView CSS 命中层 + Skyline 控件逻辑门已足够，不照搬 Web 插件方案。
3. ✅ **Dialog 关闭路径单一入口**：`DialogHost.gateFor()` 把 busy + lockExceptions 投影成闸门状态，所有按钮动作（含 cancel）统一过 `decideGate`；cancel 不再位于闸门之前，`locked={false}` 删除。`onFailed` 作为载荷契约，false / reject 共用单一 `fail()` 出口，保持打开可重试。
4. ✅ **Button loading 正交化**：`auto` 不再看定宽——有 icon/glyph 走 `mptk-btn__icon` 槽位顶替、无 icon 走 spinCircle 文字隐形占位，宽高不变；`inline` 保留为显式逃生口；无 idleWidth 测宽。
5. ✅ **失败反馈进契约**：`DialogOptions.onFailed(key)` → `DialogPayload.onFailed` → `fail()`；demo 的异步闸门接上 showToast 提示。
6. ✅ **对外出口与契约闭环**：`mp-taro-kit/ui/infra/popup-lock` 细粒度出口（index + decide 各 ESM/CJS/d.ts 三产物），登记 `docs/api/exports.md`；新增 `tests/gate.test.mjs`（判定行为级）+ tree-shaking 断言；未改 `scripts/check.mjs`——通配出口已自动覆盖新子路径，无需维护清单。
