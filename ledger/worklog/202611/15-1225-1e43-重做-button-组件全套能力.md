- `src/ui/display/Tag.tsx:5-35`：`type`(default/primary/success/warning/danger) × `size` × `variant`(solid/soft/outline) × `radius`(xs..pill) × `icon`/`iconAfter`（`库名:图标名` 字符串）；无 children 且带 icon ⇒ 正方形。Button 应沿用同一套轴名，避免库内两套词汇。

- `src/design/_tokens.scss:178-188`：`fg / fg-2 / fg-3 / fg-4`、`surface-1/2/3/base`、`border / border-strong / border-faint`，供 solid 之外三形态取色。

- `src/ui/actions/Button.ts:36-150`：`variant` 18 档（形态 + 语义色合成一轴）、`size` sm/md/lg、`icon`/`iconRight`、`color`、`loading`/`loadingText`、`block`、`dense`、`width`/`minWidth`/`maxWidth`、原生属性透传；`IconButton`（`:123-150`）是独立组件承载纯图标形态。

- 与我们的差异：它是 Web（可 hover、可量宽、可 `color-mix`），小程序没有 hover、没有 `color-mix`；且它把纯图标拆成第二个组件，本库 Tag 的做法是同组件内 `iconOnly`。

**第三方成熟实现（抓的是仓库源码/README 原文）**

| 项目 | 形态轴 | 尺寸 | 内容轴 | loading 行为 |
|---|---|---|---|---|
| Vant Weapp `packages/button/README.md` | `type`(primary/info/warning/danger) + `plain` 布尔 | normal/large/small/mini | `icon` 字符串 | loading 时左侧图标被加载图标接管；有 `loading-text` 用它的文案，无则保留原文案；`click` 不触发 |
| antd-mobile `src/components/button/button.tsx` | `color`(default/primary/success/warning/danger) + `fill`(solid/outline/none) | mini/small/middle/large | 图标进 children，无 `icon` 参数 | `loading: boolean \| 'auto'`；loading 为真时整体渲染 `loadingIcon + loadingText`（替换 children）；`disabled = disabled \|\| loading` |
| NutUI React `src/packages/button/button.tsx` | `type` + `fill`(outline/dashed/solid) | 48/40/32/28/24 | `icon`/`rightIcon`，`!children` 加 `icononly` 类 | loading 时左侧 icon 不渲染、换成内置 Loading；children 原样保留；`disabled \|\| loading` 都加禁用类并拦截 onClick |

三家共识：**loading 一律 = 前置位放转圈 + 自动禁用 + 拦截点击**；分歧只在「文字是否保留」（Vant/NutUI 保留、antd-mobile 用 loadingText 替换）。兄弟项目在保留文案之外，另给了 `loadingText=false` 时清空文案并锁宽的能力。

**本库需要额外注意的两点**

- 小程序无 hover，交互态只能靠 `hover-class`（Taro 的 `@tarojs/components` 支持）或按压态类；兄弟项目那套 `:hover` 不能照搬。
- 无 `color-mix`，浅底档只能取现成的 `-soft` 语义色变量，不能像兄弟项目那样按自定义色混出 hover。

**定稿契约（2026-11-15 用户拍板后）**

- 轴：`type`(default/primary/success/warning/danger) × `variant`(solid/soft/outline/ghost) × `size`(xs..xl) × `radius`(xs..pill)；`color` 任意品牌色覆盖 `type`；`icon`/`iconAfter`；`block`；无 children + icon ⇒ 正方形纯图标（不做 IconButton）。
- `color` 派生：solid 底色=color、字色按相对亮度选 `--mptk-surface-1` / `--mptk-fg`；soft 底色=`rgba(r,g,b, tint)`、边与字=color；outline 白底 + color 边字；ghost 只 color 字。`rgba()` 的 alpha 用变量 `--mptk-c-btn-tint`（明 / 暗各一档），需实机验证 WXSS 吃不吃「rgba 里带变量」；不吃则退回固定 alpha。
- `color` 解析：只保证 hex / rgb 可解析并派生浅底；解析不了（`var()` / 色名）时浅底退回 `--mptk-surface-2`，边与字仍用原色 —— 写进 api 文档。
- loading：`loadingMode` = `auto`（默认）/ `inline` / `circle`；auto 判据 = `block` 或显式 `width` 视为定宽走 inline，否则 circle。`circle` = 文字 `visibility:hidden` 占位 + 圈绝对居中，宽度绝对不变；`inline` = 文字前插圈，允许变宽（消费方自选）。传 `loadingText` 时按文案替换并走 inline。
- 圈径：Loader 五档（20/22/24/28/36）与按钮五档字号 1.6 倍正好对齐，不改 Loader。
- 禁用态：现有 `.mptk-btn--disabled` 把品牌色涂成 `--mptk-fg-4` 的糙做法改掉，统一走 `opacity: var(--mptk-opacity-busy)`。
- 按压态：小程序无 hover，按 Cell / Card 的既有做法走 `hoverClass`（`src/ui/display/cell/Cell.tsx:72`、`src/ui/card/Card.tsx:87`），按压只降透明度，不做颜色混算。
