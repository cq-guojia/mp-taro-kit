## Background

做两个组件：Switch 开关（传统圆形；圆角方形且两侧可自定义文字/图标）与 N 元选择块（胶囊滑块、下划线频道切换，可带图标/标题/计数/副文本）。第一轮讨论确认两者是**两个不同组件**（boolean 翻转 vs 从 N 项选 1），共享尺寸与滑动几何标准。用户明确：Button / Input 先不动，尺寸统一从这两个组件起步，将来 Button / Input 从 dsh-plugin-core 搬过来时接这套标准；demo 首页正好要用（`demo/src/pages/index/index.tsx:17-21,46-56` 现为手搓的三态主题选择器）。本轮只讨论，不落码。

## To Do

2026-11-12 深夜（Switch 已交付后）待用户拍板，本轮只讨论、不落码：

1. **段宽策略**：默认 `fit`（段宽 = 内容 + 左右内边距，容器宽 = 各段之和）还是 `fill`（撑满容器、等分）。用户要 fit，需确认 `fill` 是否保留为显式开关。
2. **fit 是否允许测量**：段宽不等时百分比定位失效，只能 `Taro.createSelectorQuery().selectAll('.mptk-seg__item').boundingClientRect()` 一次量出每段 left/width 写内联样式。
3. **Button 补尺寸轴**：Button 现在没有 `size`（40px 由 padding 8 + `--mptk-line-lg` 24 撑出来，`src/ui/actions/style/index.scss:1-14`），是否补 sm/md/lg = 32/40/48，与 Switch / Segmented 严格同轴；本库暂无 Input。
4. **圆角缩小范围**：默认 `--mptk-radius-md`(12) 降一号到 `sm`(8)。只动 Button + Segmented 容器，还是连 Cell(12) / Dialog·Toast(12·16) / Popup(16) 一起？Segmented 滑块 `sm`(8) → `xs`(4) 是否同步。
5. **半圆形态**：Button 加 `shape="pill"`（用 `--mptk-radius-pill` = 999px，**不写 50%** —— 48 高的按钮写 50% 会左右变椭圆）；Segmented 是否同轴。
6. **loading 形态**：覆盖式转圈（文字隐藏但占位）+ line 形态底部来回条，是否就按这两套。
7. **超宽滚动**：不内置（宿主外套 `ScrollView scroll-x`，指示器因与段同在一个容器内自动跟随）还是内置 `scrollable`。

另需补：demo `segmented` 页只摆了 sm 与默认 lg（`demo/src/pages/segmented/index.tsx:39-50`），三档要摆全，否则看起来「只有两个型号」。
