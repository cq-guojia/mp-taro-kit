## Process（续 2026-11-17：顶部安全区让位，真机 + Skyline 双端收口）

- 真值来自 Taro：`Taro.getWindowInfo().statusBarHeight` + `Taro.getMenuButtonBoundingClientRect()`，app 入口 `configureSafeArea()` 注入一次（`demo/src/app.tsx:79-87`）；runtime safe-area 单例零平台依赖（`src/runtime/safe-area.ts`），无胶囊端（H5 / RN）回退 44px 内容高。库与 demo 均不出现 `wx.*`。
- 公式与 `NavBar.tsx` 同口径：内容高 = `menuButton.height + max(menuButton.top - statusBarHeight, 0) × 2`；总高 = 状态栏 + 内容高。明令禁止 `(top - statusBar + height) × 2`（会把胶囊高乘两遍）。
- 三档 `insetTop`：`none` / `status-bar` / `nav-bar`；`top/left/right` 默认 `nav-bar`，`bottom/center` 默认 `none`。
- 走过的三个错与纠正：① 布尔 `safeTop` + `env()` → 三档 + API 真值；② 负 `top: calc(0px - env(safe-area-inset-top))` 把底色探到屏顶 → WebView 多让一个状态栏、Skyline 下整块被裁切顶出（用户真机 + 模拟器截图证实），按微信官方 Skyline 最佳实践改为面板/遮罩 `top: 0`、让位只加内容 `padding-top`；③ 面板自身 `padding-top: 16px` 与让位叠加，正文起点 110px、胶囊底 90px → 让位档面板顶部内边距归零，`Drawer` 同步。
