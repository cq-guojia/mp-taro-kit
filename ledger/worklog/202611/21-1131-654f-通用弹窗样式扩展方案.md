成熟项目调研（本轮）：

- NutUI（官方 v1.11.2）：`title` / `content` 配置 + `header` / `default` / `footer` 槽位；`footer-direction: horizontal | vertical` 控按钮横纵；`no-footer` / `no-ok-btn` / `no-cancel-btn` 控按钮栏。
- TDesign 小程序：Dialog 用 `actions` 数组 + `button-layout: horizontal | vertical`；槽位 `top` / `title` / `content` / `middle` / `actions` 等；官方有「带图片对话框」示例，图片头归 Dialog 的一种形态。
- Vant Weapp：`Dialog` 是标题+消息+按钮的告知确认框，`Popup` 是裸容器，标题与底部靠 slot 组合。
- antd-mobile：`Dialog` 配置式确认框、`Popup` 定位容器，分层与本库一致。

共同规律：成熟库用「头部 / 内容 / 底部」槽位 + 配置双通道，按钮横纵排布独立成轴，图片头是对话框的一种形态而非独立品类。

关键约束与坑：

- 「图片做成白色和背景接上」不能写死白色：库有明暗主题，透明异形图必须配随面板 surface 走的 token。
- 徽标浮出不能用负 margin / `gap`：Skyline 不支持，用 `position: absolute` + `transform: translateY(-<overlap>)`（百分比按容器自身算），复用 Popup 外置关闭叉的 overflow 处理方式。
- 徽标与 `closePosition` 冲突时徽标优先，面板内 `top-*` 档回落到外置档。
- 完全自定义走现有 `surface='none'`，不新造「透明模式」。

最终对外契约（用户拍板后定稿）：

- `variant: 'title' | 'image' | 'badge'`；`position: 'center' | 'bottom'`（类型层限制，运行时越界回落 `'center'`；不做 top / 左右）。
- 三档头部：`title` = 小 `icon`/`glyph` + `title` + `subtitle` 三件一体、小图标无背景不可设形状；`image` = `image`（复用 `ImageSizeInput`）+ `headerBackground`（默认透明）；`badge` = 外伸容器 + `badgeIcon`/`badgeGlyph` + 可选 `title`。
- 背景三作用域：`panelBackground`（整面板/内容区，可渐变铺满）、`headerBackground`（头部区）、`badgeBackground`（徽标容器），值 = 颜色字符串或 `{ from, to, direction? }`，走内联 style。
- `headerDivider`：头部与内容间分割线，按 variant 给推荐默认（title 开、image/badge 关），可覆盖。
- footer 三层级：配置 `actions` + `actionsLayout('row' | 'column')` + `actionsAlign`；只覆盖 `footer` 槽位；或只传 `children` + `surface='none'` 全自绘。优先级「槽位 > 配置 > 默认」。
- badge 专属：`badgeRadius`（`'none' | 'sm' | 'md' | 'lg' | 'circle' | number | string`，circle = 50%）、`badgeSize`、`badgeAlign`（`center | left | right`）、`badgeOffset`（number px / `'20%'` 面板宽）、`badgeOverlap`（number px / `'40%'` 容器自身高，默认 50%）、`badgeBorderWidth`（token 默认 2）、`badgeBorderColor`（token 默认面板 surface 色）、`badgeBackground`。没传图标就不渲染空容器。

交叉验证结论（前端 + 架构双视角 + 成熟库对照，均核到源码）：
- 需求覆盖逐条核对：① border 开关/宽/色——现只有 `badgeBorderWidth`/`badgeBorderColor`（ContentPopup.tsx:323-324），无布尔开关，且默认描边色 `var(--mptk-surface-1)`（style/index.scss:174）与面板 `var(--mptk-surface-elevated)`（layout/style/index.scss:58）暗档不同色，需修；② 背景色——`badgeBackground` 已支持纯色/渐变，改名并入对象即可；③ 内容三形态——现有仅内置 `badgeIcon` + 自绘 `badgeGlyph`（:393-394），**图片完全没有通道**；第三方样式类名也不能塞进 `badgeIcon`（`Icon.name` 必填 `库名:图标名`，`iconClass` 解析失败返回 null，Icon.tsx:26,40-41），需独立通道；④ 尺寸/偏移——`badgeSize` 只收 number、`badgeAlign='center'` 时 `badgeOffset` 被丢弃、`translateY(-${overlap})` 传负值会拼出 `translateY(--10px)` 非法串（:326-343），需支持有符号 x/y；⑤ icon 大小——现硬编码 `size="xl"`（:393）与固定字号 token（style/index.scss:182），需可覆盖。
- 评审分歧的判定：前端评审称「Skyline 单边 border+圆角失效」对徽标不适用——Spinner 那条限制特指**单边**上色（Spinner.tsx:29-30），徽标四边等宽同色不触发；但「圆形+描边+图片」叠加仍需真机观感验证，不宣称已验证。架构评审称 Icon.className 可容纳第三方类名——仅当 name 合法时成立，第三方类名无合法 name，故否决，第三方必须走独立 `<Text className>` 通道。
- 成熟库对照（通用做法，非本项目事实）：Vant Badge `offset:[x,y]`（number 补 px、字符串原样）、TDesign Badge `content:TNode` + `offset:[-10,20]` + `shape`、Ant Design Avatar `icon`/`src`/`children` 三形态、MUI Badge `badgeContent:ReactNode` + `anchorOrigin:{vertical,horizontal}`。共性：内容一个槽位/联合、偏移二元且可有负值、几何与内容分离。

最终对外契约（用户拍板：破坏式改，不保留旧平铺字段）：

```ts
type ContentPopupBadgeContent =
  | { kind: 'icon'; name: string; size?: IconSize | number }          // 内置，默认 xl
  | { kind: 'iconClass'; className: string; size?: number | string }  // 第三方/字体图标，可多个类名
  | { kind: 'image'; src: string; width?: number | string; height?: number | string; alt?: string }
  | { kind: 'glyph'; node: ReactNode }                                 // 自绘/SVG-mask 节点

interface ContentPopupBadge {
  content: ContentPopupBadgeContent
  size?: number | string                                  // 容器，默认 token 72px
  radius?: ContentPopupBadgeRadius
  background?: ContentPopupBackground
  border?: false | { width?: number | string; color?: string }  // 缺省开、默认色改 surface-elevated
  overlap?: number | string                               // 浮出量，默认 50%，translateY(-overlap)
  offset?: {
    x?: number | string                                   // 有符号，参照面板宽
    y?: number | string                                   // 有符号，用 top 承载（不拼进 translateY，避免 --10px）
    anchor?: 'center' | 'left' | 'right'                  // 默认 center
  }
}
```
